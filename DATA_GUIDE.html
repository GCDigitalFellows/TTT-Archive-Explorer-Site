Data guide

This index lists the column names in current CSV files. It defines common fields and flags fields that still need a definition. Preserved snapshots are listed separately in the project history.

Current inventory: post_inventory.csv / records.json. Grouped-name view: identity/grouped_records.json. Model inclusion: nlp/corpus_manifest.csv. Frozen fitted values: the saved nlp model-run directories. Historical baseline: attribution_revision/before/, retained solely for audit comparison; do not use it as the current author record. No live reading route uses that snapshot as its data source.
