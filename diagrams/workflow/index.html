How the archive explorer works

This guide makes the project’s concepts and workflow more understandable to human reviewers and contributors.

Four interactive, source-linked diagrams explain the project’s evidence, attribution and review logic. Open a diagram, select a node for its detail and source references, and use its Live/Still control to pause movement.

Read these as a documented workflow at private source revision 42aade8, not proof that every authorship claim is resolved or that all human/accessibility review has happened. Later project changes are outside that frozen source scope; consult the current methods and work log alongside these diagrams.
